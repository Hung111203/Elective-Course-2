# An Nam - Vietnamese Vocabulary Flashcards 🇻🇳

![Kotlin](https://img.shields.io/badge/Kotlin-1.9.0-purple?style=for-the-badge&logo=kotlin)
![Android](https://img.shields.io/badge/Platform-Android-green?style=for-the-badge&logo=android)
![Status](https://img.shields.io/badge/Status-Maintained-blue?style=for-the-badge)

**An Nam** is a modern, offline-first Android application designed to help users learn Vietnamese vocabulary effectively. Built entirely with **Jetpack Compose**, it follows modern Android architecture principles to ensure a smooth, responsive, and crash-free user experience.



## ✨ Key Features

* **Offline-First Architecture:** Users can study anytime without an internet connection. Data is synced locally.
* **Interactive Flashcards:** Smooth UI animations for flipping cards and tracking progress.
* **Vocabulary Management:** CRUD (Create, Read, Update, Delete) functionality for managing custom word lists.
* **Modern UI:** Built with Jetpack Compose for a declarative, reactive UI implementation.

---

## 🛠 Tech Stack

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material Design 3)
* **Asynchronous Processing:** Kotlin Coroutines & Flow
* **Local Database:** Room (SQLite abstraction)
* **Networking:** Retrofit (for initial data syncing)
* **Architecture:** MVVM (Model-View-ViewModel) pattern

---


## 🚀 Installation & Setup

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/Hung111203/An-Nam-App.git](https://github.com/Hung111203/An-Nam-App.git)
    ```
2.  **Open in Android Studio**
    * Select `File > Open` and choose the cloned folder.
    * Let Gradle sync the dependencies.
3.  **Run the App**
    * Connect an Android device or start an Emulator.
    * Press **Run (Shift + F10)**.
